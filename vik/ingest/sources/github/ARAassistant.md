Agentic RAG Evaluator (ARA) — a production-ready Agentic Retrieval-Augmented Generation
system with document-grounded evaluation: PDF ingestion → chunking → vector indexing →
agentic LLM reasoning, plus an LLM-as-Judge framework scoring relevance, faithfulness,
groundedness, latency, and overall quality. Built with LangChain, FAISS, OpenAI, and
Streamlit; deployed as a lightweight CPU-only Streamlit app.

Live: https://araassistant-ky7xiosunekrfmu427tt2f.streamlit.app/
