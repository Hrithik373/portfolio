# Project: Retail Sales Forecasting

Role: Time-series forecasting.

## Description

A forecasting pipeline for retail sales.

- Feature engineering: lag features, rolling statistics, seasonality, event signals.
- Models: Linear Regression, Random Forest, XGBoost, ARIMA, LSTM.
- Evaluated with production-relevant metrics: MAPE, RMSE, R².

## Stack

Pandas, TensorFlow, XGBoost, ARIMA
