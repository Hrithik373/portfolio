# github: Hrithik373/sms-spam-detection

> Draft README content — see `vik/ingest/sources/projects/sms-spam.md` for the fuller
> description.

ML-driven SMS spam detection engine. TF-IDF + NLTK/spaCy preprocessing, SMOTE for class
imbalance, and a suite of tuned classifiers (Logistic Regression, Naïve Bayes, SVM,
Random Forest, XGBoost) evaluated with F1 and ROC-AUC. Optional Flask/Streamlit
deployment.

Live: https://sms-spam-detection-uxuz5fe9icdlakvxvnvccy.streamlit.app/
